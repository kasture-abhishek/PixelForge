Format support
What goes in. What comes out.

PixelForge reads 6 still-image formats and writes 4 — processed locally, never uploaded.

JPG Lossy → Photos, camera shots, social media exports
PNG WEBP AVIF
PNG Lossless → Icons, UI assets, transparent backgrounds
JPG WEBP AVIF
WEBP Modern → Web-optimised images, often smaller than JPG and PNG
JPG PNG AVIF
AVIF Next-gen → Small files when the browser can decode AVIF
JPG PNG WEBP
GIF Still frame → Opens the first frame as a still image — animation is not preserved
JPG PNG WEBP
BMP Legacy → Uncompressed bitmaps from older software
