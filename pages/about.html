About

A local image editor, not a cloud app.

Static HTML, CSS, and JavaScript. No account and no server-side processing.

🔒
Privacy
Images are decoded and drawn in your browser. PixelForge does not upload files to a backend because it does not have one.
🛠️
Scope
Adjustments, filters, crop, resize, transform, drawing, histogram, and four export formats. It is not an AI suite and it does not convert PDFs.
📂
Limits
Maximum file size is 50 MB. Animated GIFs open as a still frame. AVIF export works only when the browser supports it.
